WN11-CC-000315

The Windows Installer feature “Always install with elevated privileges” must be disabled.

STIG remediation walkthrough · Diagnose → Remediate with PowerShell → Verify → Rescan with Tenable

✔ Tenable audit: PASSED

The finding

What the setting does

When enabled, Windows Installer runs .msi packages with SYSTEM privileges, even when a standard user launches them.

Why it is CAT I

A standard user could install a malicious package and take full control of the machine, a direct privilege-escalation path.

Required state

HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer
AlwaysInstallElevated = REG_DWORD 0
GPO: Administrative Templates › Windows Components › Windows Installer › Always install with elevated privileges = Disabled

Diagnosis: is the policy set?

Takeaway: “not configured” isn’t compliant. The STIG needs the value to exist and equal 0.

Remediation with PowerShell

$Path = "HKLM:\SOFTWARE\Policies\Microsoft\Windows\Installer"

New-Item -Path $Path -Force | Out-Null

New-ItemProperty `
    -Path $Path `
    -Name "AlwaysInstallElevated" `
    -PropertyType DWord `
    -Value 0 `
    -Force | Out-Null

Write-Host "WN11-CC-000315 remediation applied." -ForegroundColor Green
